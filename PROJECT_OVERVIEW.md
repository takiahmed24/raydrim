## 📌 Project Overview
Modern Next.js 15 App Router website with Tailwind CSS, TypeScript, and AWS Amplify deployment.

**Raydrim.com** is the official corporate web presence for Raydrim, showcasing software engineering, AI systems, game development, and digital marketing capabilities.

### Core Features
- **Next.js 15 App Router Architecture**: Built with modern React Server Components, TypeScript, and optimized static rendering.
- **Tailwind CSS & Glassmorphic Design**: Custom aesthetic featuring warm dark charcoal tones, subtle border glow, and responsive layouts across all viewports.
- **Modular Page Structure**: Complete pages for Home, About, Services, Portfolio, Pricing, Blog, Contact, Terms of Service, and Privacy Policy.
- **AWS Amplify CI/CD (`amplify.yml`)**: Continuous deployment configuration for high-performance hosting on AWS infrastructure.
